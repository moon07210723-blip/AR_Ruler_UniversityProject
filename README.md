# AR Ruler
/*
UnityとC#を使用して制作した、ARを活用した距離測定アプリケーションです。
カメラを通して現実空間を認識し、ユーザーが指定した2つの地点間の距離を測定できるように実装しました。
*/
## ソースコードの場所
/*Assets/SampleProject/ARRuler/Script*/


## 1. プロジェクト概要

/*AR環境上で現実空間の任意の地点を指定し、その後、別の地点を指定することで、2点間の距離を計算して画面上に表示するアプリケーションです。

スマートフォンのカメラを利用し、現実空間における距離を簡単に測定できる機能の実装を目的として制作しました。*/


## 2. 開発環境
/*
- Unity
- C#
- ARを利用した空間トラッキング
*/


## 3. 主な機能
/*
- カメラを利用した現実空間の認識
- 測定開始地点の指定
- 測定終了地点の指定
- 2点間の距離計算
- 測定結果のUI表示
*/

/*
プログラミング部分は自分が単独で担当しました。

主な実装内容は以下の通りです。

- AR環境での現実空間のトラッキング

実装に必要なAR機能やUnityの使用方法については、公開されている技術資料やサンプルを参考にしながら調査し、実装しました。
